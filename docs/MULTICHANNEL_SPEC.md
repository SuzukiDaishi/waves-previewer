# 多チャンネル（5.1 / 7.1 / 7.1.4 など）仕様

5.1・7.1.4 などの多チャンネル素材を扱うための仕様。対象は 5 つ。

- 素材のチャンネルレイアウト
- 再生の対応付け
- サラウンド用のミニメーター
- 出力側のスピーカー割り当て（ASIO 出力は保留。#26）
- ヘッドフォンでのモニター（HRTF）
- パンニング（エディタの Panner ツールと Multi Edits のパン。7 章）

あわせて、多チャンネルで表に出た 2 つの不具合も扱う。スペクトログラムの無限再解析と、スペクトルの縦線。

## 決定事項

| 項目 | 決定 |
|---|---|
| ミニメーター | 3ch 以上（LFE を除く）の素材では、STEREO パネルの代わりに **SURROUND パネル（俯瞰図＋音の方向）** を出す |
| レイアウトの保存 | **チャンネル数ごとの既定（prefs）＋ファイル個別の上書き（session）** |
| 再生への反映 | レイアウトは**メーターと再生の両方**に使う |
| ASIO | **保留**。Steinberg ASIO SDK の独自ライセンスを結ぶまで入れない（[#26](https://github.com/SuzukiDaishi/waves-previewer/issues/26)） |
| Dante | ASIO と同じく保留。再開するときは、Dante Virtual Soundcard（DVS）の ASIO ドライバー経由にする。Audinate の SDK は使わない |
| ヘッドフォン | 3ch 以上の素材を **HRTF で畳み込み**、両耳に出す。既定の HRTF は SADIE II D1（KU100）の 48 kHz 版を同梱する。設定は prefs |
| 仮想スピーカーの画面 | **アプリ内の浮動ウィンドウ**（「Virtual speakers (HRTF)」） |

## 1. チャンネルレイアウト

### 考え方
- 素材の各チャンネルに、**スピーカー位置**（`SpeakerPos`）を 1 つ割り当てる。割り当てない（「なし」）こともできる。これを「素材のレイアウト」と呼ぶ。
- 同じ考え方で、出力デバイスの各チャンネルにもスピーカー位置を割り当てる（「出力の割り当て」）。
- 再生は、素材のレイアウトと出力の割り当てから、スピーカー位置どうしで対応付ける（`ChannelMixMatrix`）。出力に無いスピーカーの音は、近いスピーカーへたたみ込む。

### スピーカー位置
今の `SpeakerPos`（WAVEFORMATEXTENSIBLE のチャンネルマスクの各ビット）に、9.1.6 に要る位置を足す。

| 層 | 位置 |
|---|---|
| 耳の高さ | L / R / C / Lc / Rc / Ls / Rs（側方）/ Lrs / Rrs（後方）/ Cs（後方中央）/ Lw / Rw（ワイド） |
| 上の層 | Ltf / Rtf / Tfc / Ltm / Rtm（トップサイド）/ Ltr / Rtr / Tbc / Tc（真上） |
| 方向なし | LFE（LFE2 は今回は扱わない） |

### 決め方（上が優先）
1. **ユーザーの指定**: そのファイルだけの上書き。session に保存する。
2. **ファイルのチャンネルマスク**: WAVEFORMATEXTENSIBLE。ビットの並び順にチャンネルを割り当てる。立っているビットの数がチャンネル数と合わない場合は、使わない。
3. **チャンネル数ごとの既定**: prefs に保存する。
4. **標準の WAVE の並び**: 1 / 2 / 3 / 4 / 5 / 6 / 7 / 8 / 10 / 12ch。それ以外のチャンネル数は、レイアウト無し（番号どおり）として扱う。

### プリセット
組み換えの画面では、チャンネル数に合うものだけを出す。

| 名前 | 並び |
|---|---|
| LCR (WAV) | L R C（3ch の標準） |
| 2.1 (WAV) | L R LFE（マスク 0x0B。Windows の KSAUDIO_SPEAKER_2POINT1） |
| 5.1 WAV / SMPTE | L R C LFE Ls Rs |
| 5.1 Film / Pro Tools | L C R Ls Rs LFE |
| 5.1 DTS | L R Ls Rs C LFE |
| 7.1 WAV / SMPTE | L R C LFE Lrs Rrs Ls Rs |
| 7.1 Film / Pro Tools | L C R Ls Rs Lrs Rrs LFE |
| 5.1.2 / 5.1.4 / 7.1.2 | WAV 順の床面の後ろに、上の層を前から順に並べる |
| 7.1.4 WAV / SMPTE | L R C LFE Lrs Rrs Ls Rs Ltf Rtf Ltr Rtr |
| 7.1.4 Pro Tools | L C R Ls Rs Lrs Rrs LFE Ltf Rtf Ltr Rtr |
| 9.1.6 | L R C LFE Lrs Rrs Ls Rs Lw Rw Ltf Rtf Ltm Rtm Ltr Rtr |

### WAV に書くチャンネルマスク
- 書き出しに使うライブラリ（hound）は、3ch 以上の WAV に `(1 << ch) - 1` のマスクを書く。
  - 3ch なら LCR、4ch なら L R C LFE、8ch なら L R C LFE Ls Rs Lc Rc になる。2.1 / Quad / 7.1 では、違うスピーカーを名乗ってしまう。
- そこで、書いた直後に、その行のレイアウトのマスクで書き換える（`wave::write_wav_channel_mask`）。
  - エディターの保存・リストの保存と書き出し（`export_ops` の `write_layout_mask`）: その行のレイアウト（1 章の決め方の結果）。
  - ゲインだけの保存（`wave::export_gain_wav`）: 元のファイルのマスクをそのまま写す。
  - Multi Edits の書き出し: タイムラインの出力フォーマット。
- マスクで言えないレイアウト（Film 順のように、ビットの順に並んでいないもの。スピーカーの無いチャンネルがあるもの）は、0（割り当てなし）を書く。間違ったマスクよりはよい。
- 2ch 以下は触らない。

### 組み換えの画面
- ミニメーターの SURROUND / STEREO パネル、またはチャンネルごとのメーターの右クリック →「Channel layout…」で開く。
- チャンネルごとに、スピーカー位置をプルダウンで選ぶ。プリセットも選べる。
- 保存先を選ぶ。
  - 「このファイルだけ」: session に保存する。
  - 「このチャンネル数の既定にする」: prefs に保存する。
- 同じスピーカー位置を 2 つのチャンネルに割り当てたら、警告を出す（再生ではどちらも鳴る）。
- 「標準に戻す」で上書きを消す。

### session への保存
- ファイルごとの上書きは、session（`.nwsess`）に、ファイルのパスに結びつけて持つ。
- 同時編集のマージ規則は作らない。衝突したときは、文書全体の衝突モーダルに任せる。
- session を読むだけでは書き換えない。

### チャンネルごとのメーター
- 「Ch N」ではなく、レイアウトの名前（L / R / C / LFE / Ls …）を出す。
- レイアウト無しのチャンネル数では、今までどおり「Ch N」。

## 2. 再生の対応付け
- Auto モードでは、素材のレイアウトと出力の割り当てから `ChannelMixMatrix` を作る。
  - 今は、どちらもチャンネル数ごとの標準の並びで決め打ちしている。これを、1 の決め方で求めたレイアウトに置き換える。
- 出力に無いスピーカーは、今のたたみ込みの規則に従う。上の層は同じ側の耳の高さへ、後方は側方へ、など。
- **LFE**: 出力に LFE が無いときは、センターと同じ所へ、同じ係数でたたむ。
  - ステレオのデバイスでは、L / R に −3 dB ずつ入る。センターのあるデバイスでは C に入る。
  - ITU-R BS.775 のダウンミックスは LFE を捨てる。だがそうすると、ヘッドフォンや 2 本のモニターで LFE にしか無い音が聞こえなくなるので、捨てない（2026-10 に変更）。
  - ラウドネスメーターには入れない（ITU-R BS.1770 は LFE を除く）。`ChannelMixMatrix::mix_loudness` で、メーターに渡す分から LFE を外す。
- Direct モード（番号どおり、たたみ込みなし）も残す。

## 3. サラウンドのミニメーター

### 出す条件
- 素材のレイアウトに、LFE 以外のスピーカーが 3 つ以上あるとき。STEREO パネルの代わりに SURROUND パネルを出す。
- 2ch 以下、またはレイアウト無しの素材では、今のゴニオメーターのまま。

### 描くもの（上から見下ろした図。上が前）
- **耳の高さの層**: 外周の円上に、標準の角度で各スピーカーを置く（ITU-R BS.2051 / Dolby の配置）。
  - C は 0°、L / R は ±30°、Lc / Rc は ±15°、Lw / Rw は ±60°。
  - 5.1 の Ls / Rs は ±110°。
  - 7.1 以上では、Ls / Rs（側方）は ±90°、Lrs / Rrs（後方）は ±135°。
  - Cs は 180°。
- **上の層**: 内側の円上に置く。
  - Ltf / Rtf は ±45°、Ltm / Rtm は ±90°、Ltr / Rtr は ±135°、Tfc は 0°、Tbc は 180°。
  - Tc は中心に置く。
- **各スピーカーの点**
  - 直近の RMS（ミニメーターの窓）で、大きさと明るさが変わる。
  - ピークを保持する輪を描く。クリップすると赤くなる。
  - ラベル（L / Ls / Ltf など）も出す。
- **音の方向**
  - LFE 以外のスピーカーの方向（3 次元の単位ベクトル）を、エネルギーで重み付けして足し合わせたもの（Gerzon のエネルギーベクトル rE）を、点で描く。
  - 直近約 1 秒の軌跡も残す。
  - 中心からの距離が「定位のはっきりさ」になる。1 に近いほど 1 つのスピーカーから聞こえ、0 に近いほど包まれる。
- **高さのゲージ**: 上の層に入っているエネルギーの割合を、縦のゲージで出す。
- **LFE**: 方向を持たないので、別の縦バーにする。
- **相関バー**: 前の L / R の相関を、今と同じバーで出す。

### 計算
- 今のミニメーターと同じ窓・同じ間隔で計算する。UI スレッドで、毎フレームの確保はしない。
- 計算の量は、チャンネル数 × 窓長の 2 乗和に、平滑化を加えた程度。

## 4. 出力側のスピーカー割り当てと、ASIO（保留）

### 出力の割り当て（モニター配置）
- 出力の各チャンネルに、スピーカー位置を割り当てる。
- **既定**
  - 2 / 6 / 8 / 12ch のデバイスは、標準の並び。
  - それより多いデバイスは、7.1.4（WAV 順）を 1〜12 に割り当て、残りの出力は鳴らさない。今までは、全出力に番号どおり広げていた。
  - 変えたいときは、設定で、配置（プリセット）と先頭の出力番号を選ぶ。
- 出力の割り当ては、デバイスごとに prefs に保存する。

### 上部バーの出力メーター
- デバイスに送る最終の値を出す。Volume・HRTF・スピーカーへの振り分けの後。
- **出力の数だけ**枠を出す。何も鳴っていないときも、枠は出したままにする。
  - 1〜2ch のデバイスは、横の段（今までどおり）。
  - 3ch 以上は、出力ごとの縦の列。各列の上に、その出力のスピーカー名（L / R / C / LFE / Ls …。割り当ての無い出力は番号）を、入る幅のときだけ書く。
  - 名前は、上の「出力の割り当て」から取る。
- ホバーで、デバイス名と、出力ごとのレベル（RMS とピークホールド）を出す。
- 右の dBFS の数字は、全出力の RMS。
- 出力ごとに分けて測るのは 32ch まで（`audio::METER_CH_SLOTS`）。それより多いデバイスは、残りを最後の枠にまとめる。
- M / S / TP（ラウドネス）は、素材そのものの値のまま（Volume・HRTF の前）。

### WASAPI で 7.1.4 が鳴らない理由
- WASAPI の共有モードは、Windows のサウンド設定のスピーカー構成で開く。このスピーカー構成は最大 7.1。
- そのため、普通の環境では 12ch の出力として開けず、7.1.4 はたたみ込まれる。
- 7.1.4 をそのまま鳴らすには、次のどちらかが要る。
  - ASIO（保留中）
  - 12ch 以上の WDM を出すドライバー（DVS の WDM など）

### ASIO と Dante（保留）
- 一度実装したが、**Steinberg ASIO SDK の独自ライセンスを結ぶまで、削除した**。
- 次の内容は [#26](https://github.com/SuzukiDaishi/waves-previewer/issues/26) にまとめてある。
  - ライセンスの条件と手続き
  - 削除前の実装（ドライバーの切り替え、`HKLM\SOFTWARE\ASIO` による検出、認識できないときは隠す、フォールバック、Licenses の表記）
  - 再導入のチェックリスト
- 出力側のスピーカー割り当ては、ASIO が無くても有効なので残してある。ASIO を戻すときは、ドライバーの切り替えを足すだけでよい。

## 5. 不具合の修正

### スペクトログラムの無限再解析
- **症状**: 7.1.4・2:45 の素材で、Analysis の `n/780` がいつまでも繰り返し、スペクトログラムが出ない。
- **原因**
  - スペクトログラムのキャッシュの上限（`perf.spectro_cache_bytes()`）は、RAM に応じて 22〜130MB しかない。
  - 12ch では約 200MB になり、この上限を超える。
  - そのため、解析が終わった直後に、自分自身がキャッシュから追い出される。次のフレームでまた解析を始めるので、これが永遠に続く。
- **修正**
  - 開いているタブがいま表示に使っているスペクトログラムは、追い出さない。1 つで上限を超えるときは、上限を超えて持つ。
  - 追い出しのループは、解析中・保護中の項目を飛ばして、次の古い項目へ進む。

### スペクトルの縦線
- **症状**: 表示倍率が 125%・150% などの環境で、ミニメーターのスペクトルに縦筋が入る。
- **原因**: 列ごとに描いた矩形の境目が、物理ピクセルの途中に来る。アンチエイリアスされた半透明の辺どうしが重なると、背景が透ける。
- **修正**: スペクトル全体を、隣の列と頂点を共有する 1 枚のメッシュで描く。色は頂点ごとに付ける。

## 6. ヘッドフォンでのモニター（HRTF）

- オブジェクト音声（ADM BWF / TrueHD）は、7.1.4 の仮想スピーカーに混ぜてから、ここに来る。HRTF は 12ch の 7.1.4 として扱う（docs/SPATIAL_AUDIO_SPEC.md）。

### 鳴らし方
- **対象**
  - HRTF が ON で、鳴っている素材が 2ch 以上のとき。
  - **ステレオ**は、ルームの L / R の仮想スピーカー（標準のルームで ±30°）から鳴らす。耳へ直接ではなく、2 本のモニターを前に置いたように聞こえる。
    - 「Stereo from L / R speakers」で切れる（既定は ON）。切ると、ステレオは耳へ直接出し、HRTF は 3ch 以上だけに使う。
    - 切り替えは、上部バーの HRTF の右クリックメニュー、設定の Audio Output、「Virtual speakers」ウィンドウのどれからでもできる。
    - prefs のキーは `hrtf_stereo_speakers`。前のキー `hrtf_stereo` は読まない（既定の OFF が、どの保存でも書かれていたため）。
  - モノラルはそのまま。
- **方向**
  - 各チャンネルを、1 章のレイアウトで決まったスピーカー位置の、仮想スピーカーの方向から鳴らす。
  - 「なし」のチャンネルは、チャンネル数ごとの個別の位置から鳴らす。
- **畳み込み**（`src/binaural.rs`）
  - 再生のコールバックの中で、一様分割の重畳保存法で畳み込む。
  - 分割の長さは 128 サンプル。これがそのまま遅延になる（48 kHz で 2.7ms）。
  - 全チャンネルを周波数領域で耳ごとに足すので、逆 FFT は 1 ブロックにつき左右 1 回ずつで済む。
- **切り替え**
  - 配置や HRTF を変えたときは、新旧のフィルターを 1 分割かけてクロスフェードする。
  - 停止すると、畳み込みの履歴を空にする。
- **LFE**: HRTF を通さず、両耳に同じ量を足す。ゲイン（−30〜+10 dB）と、120 Hz のローパス（任意）がある。OFF にもできる。
- **Centre ±0 dB**（既定は OFF）: 中央の音が、HRTF の ON / OFF で同じ大きさになるよう、HRTF 全体の音量を合わせる。
  - 中央の音は、C チャンネル。C がなければ L と R に同じ音（ステレオのミックスの中のモノラルの音）。
  - 合わせる先は、HRTF を使わないときの音量。ヘッドフォンには、スピーカー用の行列でステレオにたたんだ音が出るので、その行列から読む（L = R はそのままの大きさ、C は左右に −3 dB）。
  - 中央の音が通る HRIR を耳ごとに足し、ピンクノイズの重み（オクターブごとに等しく、20 Hz〜20 kHz）で音量を測る（`binaural::centre_match_gain`）。同梱の HRTF では、そのままだとステレオの L = R が約 4.5 dB、5.1 の C が約 2.5 dB、HRTF なしより大きい。L = R は低域で左右のスピーカーの音が同じ位相で重なるうえ、SOFA の読み込み（`sofar`）が正面の HRIR のエネルギーを 1 にそろえる（同梱の HRTF では +2.6 dB）ため。
  - 合わせるのは HRIR を通るチャンネルだけ。LFE は HRIR を通らないので、自分のゲインのまま。スピーカーごとのゲインと Output trim は、この上にかかる。
  - かけた量は「Virtual speakers」ウィンドウのチェックの横に出す。最大 ±24 dB。
- **ミュート・ソロ**: 畳み込みの前にかかる。
- **出力**
  - デバイスの FL / FR の出力に出す。ほかの出力は無音。
  - 「Direct channel mapping」より優先する。
- **ラウドネスメーター**: 今までどおり、スピーカー用の行列でたたみ込んだプログラムを読む。HRTF は音量と同じく「モニター」なので、ON / OFF で LUFS は変わらない。
- **書き出し**: 対象外。モニター専用。

### 仮想スピーカーの配置
- **既定**: 1 章の `SpeakerPos::direction`（ITU-R BS.775 / BS.2051・Dolby の角度）。
- **ルームのプリセット**: 既定の方向に重ねる。

| プリセット | 内容 |
|---|---|
| Standard（ITU / Dolby） | 既定のまま |
| Quad（正方形） | FL / FR は ±45°、BL / BR は ±135° |
| Cube | Quad ＋ 上の層を同じ方位・仰角 35° に置く |
| Auro-3D | 高さの層を、主スピーカーの上の仰角 30° に置く（Tfl/Tfr ±30°、Tsl/Tsr ±90°、Tbl/Tbr ±110°）。Tc は真上 |

- **スピーカーごとの上書き**: 方位、仰角（負にすれば下の層）、ゲイン。
- **位置の無いチャンネル**: チャンネル数ごとに持つ。既定は、耳の高さの円に、前から右回りに等間隔。
- **距離**: 扱わない。SOFA の測定半径のまま。

### HRTF（プロファイル）
- **同梱**: 「SADIE II D1 (KU100)」の 48 kHz 版。インストーラーが `hrtf\` に置く。
  - ほかのレートの出力では、読み込み時にリサンプリングする。
  - debug ビルドは、リポジトリの `assets/sofas` から読む。
- **ユーザーの SOFA**: 「Load SOFA…」で追加し、一覧（prefs）に残す。「Remove」は一覧から外すだけで、ファイルは消さない。
- **読み込み**: `sofar`（純 Rust の libmysofa 移植）で、ワーカーで行う。release ビルドで 1 本 0.6〜1.3 秒。
  - 出力のレートが変わると読み直す。
  - 失敗したときは、理由を表示する。

### UI の置き場所
1. **上部バー、Volume の左の「HRTF」**: クリックで ON / OFF。
   - 表示: ON で使っているときは点灯。ON だが今の素材に使っていないとき（ステレオなど）は文字を薄く。読み込みに失敗したときは警告色。
   - 右クリック: Headphones (HRTF)、Stereo from L / R speakers、Centre ±0 dB、プロファイル、Load SOFA…、Virtual speakers…
2. **ミニメーター**

## 7. パンニング（`src/panning.rs`）

アプリの中のパンは、すべてこの規則に従う。エディタの Panner ツール（試聴はリアルタイム、適用はオフライン）と、Multi Edits のトラックのパン。計算は `src/panning.rs`、ノブと表示は `src/app/ui/pan_controls.rs` に一つずつある。

### モード（`PanMode`）

| モード | 動き | 既定になるレイアウト |
|---|---|---|
| **Balance** | パンを振った側と反対側のスピーカーを、1/4 周期の cos で下げる。中央では元のまま。どちらの側も持ち上げない（L100 で右が無音）。中央の線（正面・真後ろ）にあるスピーカーと LFE はそのまま | LFE 以外の名前付きスピーカーが 2 本以下（ステレオ、2.1、モノラル → ステレオ） |
| **3D VBAP** | 音場全体を **3 次元で回し**、各チャンネルを VBAP でスピーカーに配り直す | LFE 以外の名前付きスピーカーが 3 本以上 |

- Panner ツールでは、モードを選び直せる（Balance / 3D VBAP）。Multi Edits は既定のモードだけを使う。

### 回転（`Rotation`）

- Yaw / Pitch / Roll（度）。適用は roll → pitch → yaw の順。
  - **Yaw**: 正で右へ回る。
  - **Pitch**: 正で前が上がる。
  - **Roll**: 正で右側が下がる（後ろから見て時計回り）。
- 各チャンネルの向きは、そのレイアウトでのスピーカーの方位・仰角（`SpeakerPos::direction`）。
- Multi Edits のノブは Yaw だけ（±1 で ±180°）。

### VBAP（`Speakers`）

- **高さのスピーカーがあるレイアウト**（7.1.4 など）は 3D にする。
  - スピーカーの単位ベクトルの凸包を三角形に分け、向きを含む三角形の 3 本で鳴らす（パワーで正規化）。
  - 耳の高さの輪のように、聞く位置を通る面は使わない（逆行列が無いため）。
  - 同じ平面に 4 本以上が並ぶ所（上の 4 本の正方形など）や、三角形の辺の上では、向きを含む三角形すべてのゲインを平均してから正規化する。天頂は上の 4 本に均等に分かれる。
  - 下にスピーカーが無いレイアウトでは、水平より下へ回った向きを水平面に投影する（方位は保つ）。
  - どの三角形にも入らない向き（聞く位置を囲んでいないレイアウト）は、いちばん近い三角形を使う。負のゲインは 0 にする。
- **高さのスピーカーが無いレイアウト**（5.1、7.1 など）は、水平の輪の上の 2 次元 VBAP にする。Pitch と Roll は使わない（UI では押せない）。
  - 2 本の間が 179° 以上あいている所では、VBAP が安定しないので、角度での sin / cos のクロスフェードにする。
- スピーカーの真上の向きは、そのスピーカーだけに 1.0 で出す。どの向きでも音量（パワー）は変わらない。
- **LFE はどの回転にも含めない**。LFE のチャンネルは動かさず、ほかのチャンネルが LFE へ回ることもない。スピーカー名の無いチャンネルも動かさない。

### 行列（`PanMatrix`）と、リアルタイムの試聴

- 設定は一つの行列になる（入力チャンネル → 出力チャンネルのゲイン。疎）。
  - 試聴では、出力のコールバックがこの行列をフレームごとにかける（`SharedAudio::pan`）。
  - 適用では、同じ行列を全サンプルにかける（`apply_offline`）。聞いた音と書かれる音は同じになる。
- コールバックの中でかける場所は、mute / solo の後、HRTF・スピーカー行列・ラウドネスの取り出し口の前。パンした音が、聞こえる音であり、測られる音になる。
- 行列が変わったら、今のゲインから新しいゲインへ 5 ms で直線的に動かす（`PanState`、`PAN_RAMP_SECS`）。ノブを回し続けても段差が出ない。動かしている途中で次の行列が来ても、今の値から動かし直す。
- 行列を外したとき（プレビューを止めたとき）も、元に戻るまで 5 ms で動かす。チャンネル数が変わる行列（モノラル → ステレオ）だけは、すぐに外れる。
- 行列は、その入力チャンネル数のソースにだけかける。オブジェクト音声にはかけない。
- 試聴中は、`rendered_channels()` と鳴っているレイアウトが行列の出力になる。モノラル → ステレオは、メーター・HRTF・スピーカーへの対応付けのどれから見てもステレオになる。

### エディタの Panner ツール

- Inspector の、Channel Routing の隣のツール。パラメータはタブごとに持ち、session に保存する（`ToolState.pan_*`）。
- **ステレオ**は Balance が既定。**多チャンネル**は 3D VBAP が既定（高さのスピーカーが無ければ 2D）。
- **モノラル**は、ステレオに変換してパンする。適用するとファイルは 2ch になる。
  - Balance: L / R の両方に元の音量で出してから、バランスをかける。中央では、ステレオの機器で元のモノラルを鳴らしたときと同じに聞こえる。
  - VBAP: 正面の音を Yaw で回し、FL / FR の上で VBAP にかける。中央は −3 dB の定パワー則になる。
- **Preview (live)**: ON にしてタブを再生すると、ノブを回すたびに、その音がすぐ聞こえる（バッファを作り直さないので、再生は止まらない）。Esc か、もう一度押すと OFF。OFF にしても再生は続く。
  - 緑の波形（プレビュー後の波形）は、ノブを離したときに作り直す。短いクリップ（`LIVE_PREVIEW_SAMPLE_LIMIT` 以下）で、チャンネル数が変わらないときだけ。長いクリップとモノラル → ステレオは、音だけの試聴になる。
  - 概観だけを読み込んだ長いファイルでも、試聴はできる（エンジンが鳴らしている音にかけるため）。適用はできない。
- **Apply**: ファイル全体にかける（Gain と同じ）。Custom のチャンネル表示で選んだチャンネルだけを動かす。長いクリップはワーカーで処理する。適用した後は、ノブを中央に戻す。Undo で戻せる。
- チャンネルの差し替えは Channel Routing と同じ処理を通る（`editor_replace_channels`）。チャンネル数が変わったら、チャンネルごとの Mute / Solo / 表示を初期化する。
- CLI からの適用は、まだできない（Channel Routing と同じ）。
