# Multi Edits 仕様

Tools > Multi Edits で開くタブ。複数の音声（映像ファイルの音声を含む）をトラックに並べ、
一括で再生し、1 本に結合（ミックスダウン）する。トラックにはオートメーションを付けられる。

## 決定事項

| 項目 | 決定 |
|---|---|
| 結合の出力 | まず **virtual 行**としてリストに追加する。ファイルへの保存は、既存の virtual 行の保存で後から行う（録音テイクと同じ流れ） |
| オートメーション | **Gain (dB) / Pitch (半音) / Pan / Mute**。トラックごとに、レーンとして追加する |
| パン | トラックごとの**ノブ**（`Track.pan`）。Pan レーンはノブの位置から動かす。出力に LFE 以外のスピーカーが 3 本以上あれば、**VBAP でリスナーの周りを回す**。LFE は回さない |
| 映像トラック | 映像ファイルの**音声をミックスに入れ**、再生位置の映像を**トラックごとの別ウィンドウ**（OS のウィンドウ）に出す。映像のエンコーダーが無いので、書き出しは音声のみ |
| 保存 | **session に複数**保存する。Multi Edits のタブは複数開ける |
| 出力フォーマット | タイムラインごとに選ぶ（Stereo / 5.1 / 7.1 / 7.1.4 …。`audio_channels::PRESETS`）。トラックは、フロントの 2ch へ出す「ステレオ」か、1 チャンネルだけへ出す「モノラル」 |
| チャンネル分割 | クリップの右クリックで、素材のチャンネルごとのトラックに分ける。各トラックは、そのスピーカーへのモノラル |

## 画面

```
┌ タブバー: [List] Recording  [● Multi Edit 1] x  [Multi Edit 2] x ...   ← ● は session に未保存
├──────────────┬──────────────────────────────────────────────────────┐
│ File│Len│Ch  │ 名前 [▶ Play] 時刻 [SOLO ×1] − + ↕− ↕+ Output [5.1 ▾] [Export] │
│              │            ▼M01          ▼M02                         │ ← マーカー
│              │ 0:00 ─ 0:02 ─ 0:04 ─ …  ルーラー（クリックでシーク）  │
│──────────────│────────────┬─────────────────────────────────────────│
│ aaaa.wav     │ Track 01   │ ╭──clip──╳──clip──╮                   ▐ │ ← ╳ は重なりのクロスフェード
│ bbbb.wav     │ ━━○ -3.0 dB ◔ M S │ ╰─────────────╯             ▐ │ ← 値は dB、◔ はパン。縦スクロールバー
│              │ Trk 02 · C [C] │ ╭──music (C)──╮                     │ ← [C] は出力先（チャンネル分割）
│ ...          │ ▾ Track 03 │   ╭╱──────clip─────╲╮                   │ ← 斜線がフェード
│ (リストと同期) │  │ Gain  -1.8dB × │ +0 ／＼__／＼  （目盛り線と値）       │ ← 字下げしたレーン
│              │  │ Pitch -0.2st × │ ／＼／＼___／￣＼                    │
│              │ ▾ Video 01 [Video] │  ╭╱─────clip───────╲╮            │ ← [Video] で映像ウィンドウ
│              │  │ Gain         × │                                 │
│              │            │               (+)                       │ ← トラックの追加
└──────────────┴────────────┴─────────────────────────────────────────┘
```

- **左ペイン**: リストエディタと**同じリスト**を、列だけ減らして描く。
  - 行・並び順・検索・列フィルタ・選択・スクロール位置を共有するので、どちらで操作しても両方に反映される。
  - 列は File / Length / Ch が既定。ペイン上部の「Columns」で選べ、prefs に保存される。
  - 列幅も、リストエディタとは別に持つ。
  - 行をドラッグするとタイムラインに置ける。ドラッグで Explorer に書き出す（OS への）ドラッグは、リストエディタ側で行う。
  - タイムラインの再生中に行を選んでも、その行は試聴しない（選択だけ）。試聴すると、再生中のミックスがその 1 ファイルに入れ替わり、再生ヘッドは動いているのに 1 トラック分しか鳴らなくなるため（`multi_edit_pane_must_not_audition`）。止まっているときは、これまでどおり試聴する。
- **トラックヘッダー**: 位置を決めて並べる。ヘッダーの幅からはみ出さない。
  - 1 行目: レーンを畳む ▾/▸、トラック名（長ければ … で省略）、出力先のチップ、映像トラックでは「Video」。
    - 出力先のチップ: ステレオなら「St」、モノラルなら出す先のスピーカー名（L / C / LFE / Ls …。スピーカーの無いチャンネルは「Ch N」）。
    - クリックすると、「Stereo (front pair)」と「Mono → スピーカー名」（タイムラインの出力フォーマットの各チャンネル）から選べる。Undo 1 回分。
  - 2 行目: 音量フェーダー、その値（dB。ドラッグか、クリックして入力）、パンのノブ、M / S。
    - フェーダー・値・ノブはダブルクリックで 0 dB / 中央に戻る。どれもドラッグ 1 回が Undo 1 回分。
    - ノブ: 右か上へドラッグで右へ。Shift で細かく。出力が回すときは、ノブの針がトラックの正面の向き（±180°）を指す。鳴りに効かないトラック（ステレオ出力のモノラルトラック、LFE のトラック）では押せない。
  - 行が低くて 2 行目が入らないときは、M / S を 1 行目（出力先のチップの左）に出す。Solo が見えないまま他のトラックが鳴らない、ということを起こさないため。
  - 空いた所をクリックするとトラックを選択する。ダブルクリックで名前を変える。右クリックで、レーンの追加・名前変更・削除ができる。
  - 下端をドラッグすると、その行の高さが変わる（レーンの行も同じ）。
- **クリップ**:
  - 角丸の矩形に波形を描く。名前は下地付きで表示し、クリップの幅で切る。
  - フェードは角から伸びる斜線で表す。
  - **重なり**:
    - 開始時刻の順に、奥から描く。後から始まるクリップが上に来る。
    - 上のクリップは、重なった区間だけ半透明にし（`covered_spans`）、波形を暖色で描く。下のクリップの波形・名前・端が透けて見える。
    - クロスフェードは、上のクリップが一度だけ描く。区間を薄く色付けし、等パワーの曲線 2 本（上のクリップが暖色、下のクリップが波形の色）と「X 0.60 s」を描く。下のクリップの終わりには破線を引く。
    - 包まれたクリップの下では、外側が無音なので暗く塗る。
  - **長さ未確定のクリップ**: 先頭位置の線と「名前 …」のチップだけを描く。同じ位置に複数あれば、チップを縦に積む。
  - **1 チャンネルだけ鳴らすクリップ**（チャンネル分割で作ったもの）: そのチャンネルの波形を描き、名前の後ろにスピーカー名を付ける（例: 「music (C)」）。
- **レーン**:
  - 値の目盛り線とラベルを描く（Gain: +12〜−48 dB、Pitch: ±24、Pan: L/C/R、Mute: On/Muted）。行が低いときは、ラベルを間引く。
  - 見出しには、再生ヘッドの位置での値を出す。
  - Pan レーンの見出しは、出力がバランスなら L/R の %、回すなら L/R の角度（L90° など）。
  - 鳴りに効かない Pan レーン（ステレオ出力のモノラルトラック、LFE のトラック。`multi_edit::track_pans`）は、見出しに値の代わりに「mono: no pan」と出す。新しく Pan レーンを足すこともできない。
  - 畳んでいるときは、各レーンの線を、パラメータごとの色でクリップの行に重ねて描く。
- **SOLO の表示**: どれかのトラックが Solo なら、ヘッダーの時刻の右に「SOLO ×N」を出す。ホバーで Solo のトラック名、クリックで全トラックの Solo を外す（Undo 1 回分）。
- **マーカー**: ルーラーに旗を立て、全レーンに破線を引く。
- **再生ヘッド**: ルーラーから全レーンを縦に貫く線。
- **映像ウィンドウ**:
  - 「Video」をオンにした映像トラックごとに、OS の別ウィンドウを開く。エディタの「別ウィンドウで映像」と同じ仕組み。
  - そのトラックで再生ヘッドの下にあるクリップの映像を映す。複数同時に開ける。
  - ウィンドウを閉じると「Video」がオフになる。
  - 映像クリップには、リストのポスター画像（取れた場合）を先頭に表示する。
  - 常にこのアプリのすぐ手前に出る（Windows）。エディタの「別ウィンドウで映像」も同じ。
    - メインウィンドウを**オーナー**にした、オーナー付きのウィンドウにする（`src/app/window_owner.rs`）。
    - メインを押しても後ろに回らない。メインを最小化すると一緒に隠れる。ほかのアプリより手前には出ない。
    - egui の `ViewportBuilder` にはオーナーを指定する方法が無い。そこで、ウィンドウができた後に、UI スレッドのウィンドウからタイトルで探して `GWLP_HWNDPARENT` を設定する。

## 操作

| 操作 | 動作 |
|---|---|
| 左の行（複数可）をトラックへドラッグ | ドロップした位置（吸着後）から隙間なく並べる。トラックの無い所に落とすと新しいトラックを作る。映像ファイルは映像トラックへ。ドラッグ中の表示は下の「ドロップ前の表示」 |
| クリップ本体をドラッグ | 移動（同じ種類のトラックへ縦にも） |
| クリップの左右端をドラッグ | トリム（元ファイルは変えない） |
| クリップ上端の角をドラッグ | フェードイン / アウトの長さ |
| クリップをクリック | そのクリップだけを選び、元の行をリストでも選択する。重なった区間では、上（後から始まる方）のクリップ |
| Ctrl+クリック / Shift+クリック | 選択の入れ外し / 選択に追加 |
| トラックの空いた所からドラッグ | 矩形に掛かったクリップを、トラックをまたいで選ぶ（範囲選択）。Ctrl / Shift を押して始めると、今の選択に足す |
| Ctrl+A / Esc | タイムラインのクリップを全部選ぶ / 選択を外す（カットツール中の Esc はツールを抜ける） |
| C / ヘッダーの「✂ Cut」 | カットツールの入り・切り（Esc でも抜ける）。ツールの間は、クリップをクリックするとその位置（吸着後）で分割する。クリップの移動・トリム・フェードは効かない |
| Alt+クリップをクリック | その位置（吸着なし）で分割する |
| ↑↓ | トラックを選ぶ。選択中のトラック（なければ選択中のクリップのトラック）から上下に移り、端で止まる。何も選んでいなければ ↓ は最初、↑ は最後のトラック。画面の外なら見える位置までスクロールする |
| トラックヘッダーをクリック → Delete | トラックを削除 |
| S / Delete（Backspace）/ Ctrl+D | 再生ヘッドで分割 / 選択中のクリップかトラックを削除 / 複製 |
| Ctrl+C / Ctrl+X / Ctrl+V | 選択中のクリップをコピー / カット / 再生ヘッドの位置へペースト（下の「コピーとペースト」）。クリップとトラックの右クリックメニューからも |
| ←→ | 再生ヘッドを目盛り 1 つ分動かす（Ctrl で 1px 分。押し続けると加速）。途中にマーカーがあれば、そこで止まる |
| Alt+←→ | 選択中のクリップを目盛り 1 つ分動かす（押し続けても Undo は 1 回分） |
| M（エディタのマーカーと同じキー割り当て） | 再生ヘッドの位置にマーカーを追加 |
| マーカーの旗 | クリックでシーク。ドラッグで移動、ダブルクリックで名前変更。右クリックで名前変更・削除 |
| Space / ルーラー | 再生・停止 / シーク |
| ホイール / Shift+ホイール | 横スクロール / 縦スクロール |
| Ctrl+ホイール / Ctrl+Shift+ホイール | 横ズーム / 縦ズーム（ヘッダーの − + ↕− ↕+ でも同じ） |
| レーン: 空いた所をクリック | 点を追加 |
| レーン: 点を押してドラッグ | 押した瞬間につかんで移動（前後の点は越えない） |
| レーン: 点をダブルクリック・右クリック | 時刻と値を数値で入力する。点の削除もここから |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す（タイムラインごと） |
| 名前の入力欄（タイムライン・トラック・マーカー） | Enter か欄の外のクリックで確定、Escape で取り消し |

- **吸着**: クリップの移動・トリム・フェード、リストからのドロップ、点の移動、マーカーの移動、ルーラーでのシークは、次のうち近いものに吸い付く（画面上 8px 以内）。Alt を押している間は吸い付かない。
  - 他のクリップの端
  - 再生ヘッド
  - マーカー
  - 目盛りの縦線
  - 動かすクリップとドロップするクリップは、先頭と末尾のうち近いほうが吸い付く。
- **長さがまだ分からない行**:
  - 置ける。長さ 0 の「未確定クリップ」（`Clip.len_pending`）として、その位置に置く。まとめて置いた次の行は、同じ位置から続ける。
  - リストのメタデータ、asset、virtual 行、ミックス用のデコードのどれかで長さが分かったら、毎フレームの処理（`multi_edit_resolve_pending`）で確定させる。
  - 確定すると、同じドロップで直後に置いたクリップ（`Clip.follows`）のうち、まだ元の位置にあるものを、その長さの分だけ後ろへずらす（連鎖する）。こうして隙間なく並んだ状態を保つ。ユーザーが動かしたクリップは動かさない。
  - 長さが分かったことは編集ではない。Undo に積まず、未保存の印（●）も付けない。ミックスだけ作り直す。
  - 未確定クリップは、鳴らない。クロスフェードの計算にも入らない。トリム・フェード・分割もできない。
  - 未確定クリップがある間、Export は押せない。
- **ドロップ前の表示**: リストの行をトラックの上まで持ってくると、離す前に、置かれるクリップをそのまま描く。
  - 半透明のクリップを隙間なく並べ、それぞれに名前と長さを出す。長さが分からない行は、先頭の線とチップで描き、上のラベルに「(n not read yet)」と添える。
  - 全体の開始と終了に縦線を引き、行の上に「開始 – 終了・合計の長さ・個数」を出す。
  - 映像ファイルが混ざっていれば、映像トラックへ行く分を行の下側に薄く描き、「→ Video track」と添える（音声トラックへ行く分も同様）。
  - 離すと、描いたとおりの位置に置かれる。
  - 行の長さはドラッグの始めに 1 回だけ調べる（選択はリスト全体のこともあるため、毎フレームは調べない）。
- **名前の入力欄**:
  - 開いたときに 1 回だけキーボードを取る。欄の外のクリック、Enter、フォーカスの移動で確定し、Escape で取り消す。
  - 日本語などの変換中は、Enter と Escape を変換のものとして扱い、名前は確定も取り消しもしない。欄の外のクリックは変換中でも確定する。
  - Windows の egui-winit は、IME が処理したキーをアプリに渡さない。ほかの環境で渡ってきても、同じ扱いになるようにしてある。
- **複数選択**:
  - 選択は `MultiEditUi.selected_clips` に持つ。`selected_clip` は主のクリップ（最後に押したもの。ドラッグでつかんだもの）。選択を変えるときは `multi_edit_select_clips` を通す。リストでも元の行をまとめて選ぶ。
  - 次の操作は、選択中のクリップ全部に効く。どれも Undo 1 回分。
    - Delete
    - ドラッグ / Alt+←→ での移動
    - Ctrl+C / X / V
    - Ctrl+D
    - S
    - 右クリックメニュー
  - 選択外のクリップを押すと、まずそのクリップだけを選ぶ。
  - トリム・フェード・カットツール・Alt+クリックは、押したクリップ 1 つだけ。
  - **まとめて動かす**（`MultiEditDoc::move_group`）
    - ドラッグを始めたときの位置からの差で、全部を動かす。
    - 吸着は、つかんだクリップに対して行う。グループの他のクリップの端は、吸着先にしない。
    - 0 秒より前には行かない。グループ全体がそこで止まる。
    - 縦に動かしたときは、全部が同じ段数だけトラックを移る。移り先が無いか種類が違うクリップが 1 つでもあれば、時間方向だけ動かす。
  - **Ctrl+D**: グループ全体の長さだけ後ろに、各クリップを同じトラックへ複製する。
- **コピーとペースト**:
  - クリップボードはアプリの中だけで持つ。選択中のクリップ（ソース・切り出し位置・長さ・フェード）と、それぞれの元のトラックの種類、一番上のクリップから何段下のトラックか、を覚える。OS のクリップボードには触れない。別のタイムラインにも貼れる。
  - 一番早いクリップを再生ヘッドの位置にして、間隔を保って貼る。停止中は、貼った後に再生ヘッドをグループの末尾へ進めるので、Ctrl+V を続けて押すと隙間なく並ぶ。再生中は再生ヘッドを動かさない（音が飛ぶため）。
  - 一番上のクリップを貼る基準のトラックは、次の順で、そのクリップと同じ種類のものを選ぶ。どれも無ければ新しく作る。ほかのクリップは「基準 + 段差」のトラックへ貼る。そこが無いか種類が違えば、そのクリップの種類で同じ順に選ぶ。
    1. 選択中のトラック（トラックの右クリックメニューから貼ったときは、そのトラック）
    2. 選択中のクリップのトラック
    3. コピー元のトラック
    4. 同じ種類の最初のトラック
  - 貼ったクリップをすべて選択する。1 回のペーストが Undo 1 回分。
  - Windows では、クリップボードに文字列が無いと egui は Ctrl+V を知らせない。キーボードフック（`os_paste_key`）の合図でも貼る。どちらが来ても、1 回の押下で貼るのは 1 回。
- **チャンネルごとに分割**（クリップの右クリック →「Split into channels (N)」。`MultiEditDoc::split_clip_by_channel`）
  - 右クリックしたクリップ 1 つだけに効く（ほかに選択があっても）。Undo 1 回分。
  - 元のトラックのすぐ下に、素材のチャンネル数だけトラックを作る。元のクリップは消える（元のトラックは残る）。
  - 新しいトラック:
    - 名前は「元のトラック名 · L」など。
    - フェーダー・M / S・行の高さ・レーンの畳みは、元のトラックのものを写す。
    - レーンは、Gain / Pitch / Mute を写す（id は新しくする）。パン（ノブと Pan レーン）は、新しいトラックで鳴りに効くとき（出力が回し、LFE でない）だけ写す。
    - 出力先は、そのチャンネルのスピーカーと同じスピーカーの、タイムラインのチャンネル。タイムラインにそのスピーカーが無ければ、ステレオ（フロントの 2ch へ）にする。
  - 新しいクリップは、元のクリップの位置・切り出し・長さ・フェードをそのまま持ち、`Clip.channel` でそのチャンネルだけを鳴らす。
  - **タイムラインがステレオ（またはモノラル）で、素材が 3ch 以上**なら、先にタイムラインの出力フォーマットを素材のレイアウトにする（トーストで知らせる）。ステレオのままでは、チャンネルを分けて出せないため。
  - 素材のレイアウトは、リストでの指定（`channel_layout_ops::channel_layout_for`）。無ければ標準の並び。13ch 以上で標準が無ければ、スピーカーの無いチャンネル（`-`）として扱い、同じ番号のチャンネルへ出す。
  - 分割できないクリップでは、メニューの項目を押せなくし、ホバーで理由を出す: 素材がモノラル / もう 1 チャンネルだけ / 映像トラックのクリップ（絵がトラックの数だけ増えるため）/ 長さが未確定 / 素材を読み込み中 / 素材が読めない。
  - 分割しても音は変わらない。分割したタイムラインのミックスは、素材の各チャンネルとサンプル単位で一致する（`multi_edit_render` のテスト）。
- **出力フォーマット**（ヘッダーの「Output」）
  - Stereo のほか、`PRESETS` のどれでも選べる。今の形式がプリセットに無い（分割した素材の並び）なら、それも並べる。
  - 変えると、モノラルのトラックは、同じスピーカーのチャンネルへ付け替える。新しい形式にそのスピーカーが無いトラックはステレオに戻し、その本数をトーストで知らせる（`MultiEditDoc::set_output_layout`）。Undo 1 回分。
- **停止時の再生ヘッド**: エディタの設定「Pause Resume」に従う。Return to last start なら再生を始めた位置に戻り、Continue from pause なら止めた位置に残る。最後まで再生して止まったときも同じ。
- **スクロールの限度**: 横は、最後のクリップの終わりが画面の中央に来るところまでしか進まない。縮小は、全体と少しの余白が収まるところまで。

## 音の作り方

- 再生も書き出しも、**バックグラウンドで作ったミックス**を鳴らす（再生エンジンは 1 本の波形を鳴らすため）。
  - 編集後、少し待ってから作り直す（`MULTI_EDIT_RENDER_DEBOUNCE`）。
  - 再生中は、再生位置を保ったまま差し替える。
- **トラックごとの処理順**:
  1. クリップを並べる（トリム・フェード・重なりのクロスフェード）
  2. Pitch
  3. Gain × フェーダー
  4. Mute / M / S
  5. パンを通してマスターへ足す（下の「チャンネル」と「パン」）。出力が回すとき、パンはどのチャンネルに届くかを決めるので、ここで行う。
- **重なりのクロスフェード**: 同じトラックでクリップが重なると、等パワー（sin / cos）でクロスフェードする。
  - 一部だけ重なる場合は、重なった区間全体でクロスフェードする。
  - 完全に包まれる場合は、内側のクリップの両端で 10 ms クロスフェードし、その間は外側のクリップを無音にする。
- **元の音**: リストでその行が今鳴らす音を使う。
  - エディタで編集中なら編集後の音、virtual 行ならその音。
  - リストのゲイン変更も反映する。
- **サンプルレート**:
  - 再生用のミックスは `out_sr` で作る。ミックスと各素材（`LoadedSource.playback`）は、作ったときのレートを持つ。
    - エディタでファイルを開くと、出力デバイスがそのファイルのレートで開き直されることがある。古いレートのミックスをそのまま鳴らすと速さが変わる（48 kHz 用を 44.1 kHz で鳴らすと遅く低くなる）。
    - そこで、ミックスは作ったレートでしか「最新」と見なさない（`current_mix`）。レートの違うミックスは鳴らさず、作り直してから鳴らす。作っている途中でレートが変われば、その結果は捨てる。
    - 素材は、デコード済みの `native` から新しいレートへ変換し直す（ファイルは読み直さない）。
  - 書き出しはタイムラインの `timeline_sr` で作る。`timeline_sr` の既定は、最初に置いたクリップの `file_sr`。
- **チャンネル**:
  - ミックスのチャンネル数は、タイムラインの出力フォーマットのチャンネル数（既定はステレオ）。
  - **ステレオのトラック**は 2ch で作る。
    - クリップの素材がモノラルなら両側へ出す。3ch 以上は、偶数番目のチャンネルを L、奇数番目を R として平均する。
    - マスターでは、出力フォーマットの FL / FR へ足す。FL / FR が無ければ最初の 2 チャンネル、出力がモノラルなら左右の平均を 1 チャンネルへ。
  - **モノラルのトラック**は 1ch で作り、マスターの、そのチャンネルだけへ足す。出力フォーマットに無い番号なら鳴らさない。
    - クリップが 1 チャンネルだけ鳴らすなら、そのチャンネル。そうでなければ全チャンネルの平均。
  - ステレオのトラックに置いた 1 チャンネルのクリップは、そのチャンネルを両側へ出す。
- **再生**: タイムラインの出力フォーマットを、ミックスのスピーカーとして再生エンジンに渡す（`playing_source_layout`）。
  - 5.1 のタイムラインは、5.1 のデバイスならそのまま、ステレオのデバイスなら標準のたたみ込みで、ヘッドフォンなら HRTF で鳴る。
  - 再生中に出力フォーマットを変えても、次のミックスから付いてくる。
- **時刻は秒で持つ**。サンプルレートが変わってもクリップの位置が動かないようにするため。
- **パン**: 値は、ノブ（`Track.pan`、−1〜+1）に Pan レーンの値を足したもの（Gain レーンとフェーダーの関係と同じ）。
  - **出力がバランスのとき**（ステレオ、2.1、モノラル。LFE 以外のスピーカーが 2 本以下）: 中央では左右そのまま。片側へ振ると反対側を 1/4 周期の cos で下げる（L100 で右が無音）。どちらの側も持ち上げない。モノラルのトラックはパンしない。
  - **出力が回すとき**（LFE 以外のスピーカーが 3 本以上。`multi_edit::pan_rotates` = `panning::PanMode::default_for`）: トラックを**リスナーの周りに回す**（Yaw）。±1 で ±180°（右が正）。
    - VBAP の規則は、エディタの Panner ツールと共通（`docs/MULTICHANNEL_SPEC.md` の 7 章、`src/panning.rs`）。高さのスピーカーがある出力では 3D、無ければ水平の輪の 2D。**LFE は含めない**。スピーカー名の無いチャンネルも含めない。
    - ステレオのトラックは、FL / FR の向き（±30°）にある 2 つの音を回す。
    - モノラルのトラックは、自分のスピーカーの向き（高さのスピーカーなら、その仰角のまま）から回す。
    - **LFE に出すトラックは回さない**（そのまま LFE へ）。
    - ノブが 0 なら、これまでどおり直接出す（チャンネル分割したタイムラインが素材とサンプル単位で一致するように）。
  - Pan レーンがあるときは、1 ms ごとにパンを計算し、その間のゲインを直線で補間する（動かしてもクリックしない）。
- **Mute レーン**は階段状。切り替えの瞬間は 5 ms でフェードし、クリックノイズを出さない。

## 結合（Export）

1. `timeline_sr` で頭から最後までミックスする（worker で実行し、進捗とキャンセルを出す）。
2. float32 の一時 WAV に、出力フォーマットのチャンネル数で書く。
3. ファイルを裏付けにした virtual 行として追加し、選択する。長さ・レベル・波形は、メタデータ worker（`MetaTask::VirtualFile`）が埋める。
4. 出力フォーマットが、そのチャンネル数の標準の並びでなければ（5.1 Film など）、できた行にそのレイアウトを付ける（`set_channel_layout_override`。session に残る）。

## 保存

- `ProjectFile.multi_edits` に保存する。中身は次のとおり。
  - タイムライン・トラック・クリップ・レーン・マーカー
  - 行の高さ・レーンの畳み・映像ウィンドウの表示
  - 表示状態（ズーム、横と縦のスクロール、縦ズーム）
  - 出力フォーマット（`MultiEditDoc.layout`。`FL,FR,FC,LFE,BL,BR` の形。ステレオは空）、トラックの出力先（`Track.output`）、クリップの鳴らすチャンネル（`Clip.channel`）
  - どのフィールドも既定値付きなので、古い session も開ける。
- **id はすべてランダム**にする（書き手が複数いると連番は衝突するため）。
- **元の参照**:
  - ファイルは session の path_mode に従ったパスで持つ。
  - virtual 行は asset id も持ち、パスが合わないときは asset id で探す。
  - 見つからないクリップは missing として無音にする。
- 同時編集のマージ規則は作らない。衝突したら、文書全体の衝突モーダルに任せる。
- **未保存の印（●）**:
  - タイムラインごとに編集回数を数え、最後に session へ保存したとき（または開いたとき）の回数と違えば、タブに ● を付ける。
  - ズームやスクロールは数えない。
  - session に一度も保存していないタイムラインには ● が付き、終了時の確認にも含まれる。
- **タブ**:
  - 閉じても（x）タイムラインは session に残る。Tools > Multi Edits から開き直せる。
  - タイムラインの削除は、タブの右クリックから行う。
