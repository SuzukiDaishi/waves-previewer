# Multi Edits 仕様

Tools > Multi Edits で開くタブ。複数の音声（映像ファイルの音声を含む）をトラックに並べ、
一括で再生し、1 本に結合（ミックスダウン）する。トラックにはオートメーションを付けられる。

## 決定事項

| 項目 | 決定 |
|---|---|
| 結合の出力 | まず **virtual 行**としてリストに追加する。ファイルへの保存は、既存の virtual 行の保存で後から行う（録音テイクと同じ流れ） |
| オートメーション | **Gain (dB) / Pitch (半音) / Pan / Mute**。トラックごとに、レーンとして追加する |
| 映像トラック | 映像ファイルの**音声をミックスに入れ**、再生位置の**映像を小窓に表示**する。映像のエンコーダーが無いので、書き出しは音声のみ |
| 保存 | **session に複数**保存する。Multi Edits のタブは複数開ける |

## 画面

```
┌ タブバー: [List] Recording  [Multi Edit 1] x  [Multi Edit 2] x ...
├──────────────┬──────────────────────────────────────────────┐
│ File│Len│Ch  │ 時間ルーラー（クリックでシーク）       [▶] [Export] │
│──────────────│──────────┬───────────────────────────────────│
│ aaaa.wav     │ Track 01 │ ╭────────clip────────╮          ▐ │
│ bbbb.wav     │ ─○─ M S  │ ╰────────────────────╯          ▐ │ ← 縦スクロールバー
│ ...          │ Track 03 │   ╭╱──────clip─────╲╮            │ ← 斜線がフェード
│ (リストと同期) │  ├ Gain  │   ／＼__／＼                    │ ← トラックの下に字下げしたレーン
│              │  └ Pitch │  ／＼／＼___／￣＼               │
│              │ Video 01 │        ╭╱─────clip───────╲╮      │
│              │  └ Gain  │                                   │
│              │          │               (+)                 │ ← トラックの追加
└──────────────┴──────────┴───────────────────────────────────┘
```

- **左ペイン**: リストエディタと**同じリスト**を、列だけ減らして描く。
  - 行・並び順・検索・列フィルタ・選択・スクロール位置を共有するので、どちらで操作しても両方に反映される。
  - 列は File / Length / Ch が既定。ペイン上部の「Columns」で選べ、prefs に保存される。
  - 列幅も、リストエディタとは別に持つ。
  - 行をドラッグするとタイムラインに置ける。ドラッグで Explorer に書き出す（OS への）ドラッグはリストエディタ側で行う。
- **トラックヘッダー**:
  - トラック名（ダブルクリックで名前を変更）、音量フェーダー、M / S。
  - 右クリックで、レーンの追加・名前変更・複製・削除。
- **クリップ**: 角丸の矩形に波形を描く。フェードは角から伸びる斜線で表す。
- **再生ヘッド**: ルーラーから全レーンを縦に貫く線。
- **映像プレビュー**: タイムラインに映像クリップがある間、移動・リサイズできる小窓「Video」に、再生ヘッド位置の映像を出す。
  - 映すのは、一番上の映像トラックにある、再生ヘッドの下のクリップ。
  - デコードはエディタの映像パネルと同じ worker（先読みあり）で行う。開くファイルは表示中の 1 本だけ。
  - 映像クリップには、リストのポスター画像（取れた場合）を先頭に表示する。

## 操作

| 操作 | 動作 |
|---|---|
| 左の行（複数可）をトラックへドラッグ | ドロップした位置から隙間なく順に並べる。トラックの無い所に落とすと新しいトラックを作る。映像ファイルは映像トラックへ |
| クリップ本体をドラッグ | 移動（同じ種類のトラックへ縦にも）。他のクリップの端と再生ヘッドに吸着する（Alt で吸着しない） |
| クリップの左右端をドラッグ | トリム（元ファイルは変えない） |
| クリップ上端の角をドラッグ | フェードイン / アウトの長さ |
| クリップをクリック | 選択し、元の行をリストでも選択する |
| S / Delete（Backspace）/ Ctrl+D | 再生ヘッドで分割 / 削除 / 複製 |
| Space / ルーラー | 再生・停止 / シーク |
| Ctrl+ホイール / Shift+ホイール | 横ズーム / 横スクロール |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す（タイムラインごと） |

## 音の作り方

- 再生も書き出しも、**バックグラウンドで作ったミックス**を鳴らす（再生エンジンは 1 本の波形を鳴らすため）。
  - 編集後、少し待ってから作り直す（`MULTI_EDIT_RENDER_DEBOUNCE`）。
  - 再生中は、再生位置を保ったまま差し替える。
- **トラックごとの処理順**:
  1. クリップを並べる（トリム・フェード）
  2. Pitch
  3. Gain × フェーダー
  4. Pan
  5. Mute / M / S
  6. マスターへ足す
- **元の音**: リストでその行が今鳴らす音を使う。
  - エディタで編集中なら編集後の音、virtual 行ならその音。
  - リストのゲイン変更も反映する。
- **サンプルレート**:
  - 再生用のミックスは `out_sr` で作る。
  - 書き出しはタイムラインの `timeline_sr` で作る。`timeline_sr` の既定は、最初に置いたクリップの `file_sr`。
- **チャンネル**:
  - ミックスはステレオ。モノラルは両チャンネルへ出す。
  - 3ch 以上は、偶数番目のチャンネルを L、奇数番目を R として平均する。
- **時刻は秒で持つ**。サンプルレートが変わってもクリップの位置が動かないようにするため。
- **Pan はバランス**。中央では左右そのまま。片側へ振ると反対側を 1/4 周期の cos で下げる（L100 で右が無音）。どちらの側も持ち上げない。
- **Mute レーン**は階段状。切り替えの瞬間は 5 ms でフェードし、クリックノイズを出さない。
- **レーンの点**:
  - 空いた所をクリックすると点を追加する。
  - 点をドラッグすると移動する（前後の点は越えない）。
  - 点をダブルクリックまたは右クリックすると削除する。

## 結合（Export）

1. `timeline_sr` で頭から最後までミックスする（worker で実行し、進捗とキャンセルを出す）。
2. float32 の一時 WAV に書く。
3. ファイルを裏付けにした virtual 行として追加し、選択する。長さ・レベル・波形は、メタデータ worker（`MetaTask::VirtualFile`）が埋める。

## 保存

- `ProjectFile.multi_edits` に保存する。中身は、タイムライン・トラック・クリップ・レーンと表示状態（ズームとスクロール）。
- **id はすべてランダム**にする（書き手が複数いると連番は衝突するため）。
- **元の参照**:
  - ファイルは session の path_mode に従ったパスで持つ。
  - virtual 行は asset id も持ち、パスが合わないときは asset id で探す。
  - 見つからないクリップは missing として無音にする。
- 同時編集のマージ規則は作らない。衝突したら、文書全体の衝突モーダルに任せる。
- **タブ**:
  - 閉じても（x）タイムラインは session に残る。Tools > Multi Edits から開き直せる。
  - タイムラインの削除は、タブの右クリックから行う。

## 段階

1. **基盤**: タブ、同期する左ペイン、トラックとクリップ、一括再生、Export → virtual 行、session 保存、Undo
2. **オートメーション**: Gain / Pan / Mute → Pitch
3. **映像**: 映像クリップのサムネイル、映像プレビューの小窓
