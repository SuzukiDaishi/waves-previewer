# Video test fixtures

The two MP4 files in this directory are deterministic six-second, 1920x1080,
30 fps H.264 fixtures generated by `commands/generate_video_test_samples.ps1`.

- `video_sync_6s_30fps.mp4` includes an AAC track with an 80 ms tone at each
  whole second. AAC is intentionally unsupported, so the app must label it
  `AAC UNSUPPORTED`, use a seekable silent transport, and still follow the
  burned-in presentation timestamp/yellow marker without a frame offset.
- `video_no_audio_6s_30fps.mp4` has the same picture and deliberately has no
  audio track. It must be reported as `NO AUDIO`, not as a file/decode error,
  and must still provide a seekable silent transport.

Regenerate both files from the repository root with:

```powershell
powershell -ExecutionPolicy Bypass -File commands\generate_video_test_samples.ps1
```
